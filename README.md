📱 Responsive interface
🛠️ Tech Stack

Frontend: React · Vite · Tailwind CSS · Axios

Backend: Node.js · Express.js · CORS

🚀 Run Locally
Clone
git clone https://github.com/farheenayy33/SoftSuite-Task-Password-Generator.git
cd SoftSuite-Task-Password-Generator

Install Frontend
npm install

Install Backend
cd Server
npm install

Start Backend
npm start

Start Frontend

Open a new terminal in the project root:

npm run dev


Open the local URL provided by Vite.
