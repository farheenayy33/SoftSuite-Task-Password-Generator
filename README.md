## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/farheenayy33/SoftSuite-Task-Password-Generator.git
cd SoftSuite-Task-Password-Generator
````

### 2. Install Frontend Dependencies

```bash
npm install
```

### 3. Install Backend Dependencies

```bash
cd Server
npm install
```

### 4. Start the Backend

```bash
node server.js 
```

### 5. Start the Frontend

Open a new terminal in the project root:

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.
