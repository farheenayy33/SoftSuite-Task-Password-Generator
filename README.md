🔐 React Node Password Generator

A full-stack password generator built with React, Vite, Tailwind CSS, Node.js, and Express.js.
It allows users to generate strong passwords through a simple and responsive interface.

✨ Features
Custom password length
Uppercase & lowercase characters
Numbers and special characters
One-click password generation
Copy generated password
Responsive UI
🛠️ Tech Stack
Frontend: React, Vite, Tailwind CSS, Axios
Backend: Node.js, Express.js, CORS
📂 Project Structure
React-Node-Password-generator/
├── src/                  # React frontend
├── public/               # Static assets
├── Server/               # Node.js + Express backend
│   ├── password.js       # Password generation logic
│   └── server.js         # Express server
├── package.json
└── vite.config.js

🚀 Getting Started
Clone the Repository
git clone <repository-url>
cd React-Node-Password-generator

Install Frontend Dependencies
npm install

Install Backend Dependencies
cd Server
npm install

Run the Backend
npm start

Run the Frontend

Open a new terminal from the project root:

npm run dev


Open the local URL provided by Vite in your browser.
