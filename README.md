✨ Features

🔢 Custom Length — Choose the desired password length.

🔤 Character Options — Include uppercase, lowercase, numbers, and special characters.

⚡ Instant Generation — Generate passwords with a single click.

📋 Copy to Clipboard — Easily copy the generated password.

📱 Responsive UI — Works smoothly across different screen sizes.

🚀 Getting Started
1️⃣ Clone the Repository
git clone https://github.com/farheenayy33/SoftSuite-Task-Password-Generator.git

cd SoftSuite-Task-Password-Generator

2️⃣ Install Frontend Dependencies
npm install

3️⃣ Install Backend Dependencies
cd Server
npm install

4️⃣ Start the Backend
npm start

5️⃣ Start the Frontend

Open a new terminal in the project root:

npm run dev


Open the local URL provided by Vite in your browser.
